## 2024-05-18 - Missing loading="lazy" on above-the-fold images
**Learning:** Some images in this project are missing `loading="lazy"`. However, adding lazy loading to all images is not optimal because above-the-fold images should load eagerly for best performance (LCP). We should add lazy loading only to below-the-fold images. In this project, the only static images we have are mostly profile pictures, which appear in lists, or in individual pages. For lists (like `equipe.html`), images lower on the page should have lazy loading. For individual pages, the main profile picture is usually above the fold, so we shouldn't lazy-load it, but the ones in the 'corredor' (nav at the bottom) should be lazy-loaded. Wait, actually, adding lazy loading to below-the-fold images is a standard good practice. Let's see which ones we can safely lazy-load.
## 2024-05-18 - Preconnecting to fonts.gstatic.com for Google Fonts
**Learning:** The HTML files load fonts from Google Fonts using `<link rel="preconnect" href="https://fonts.googleapis.com">`. However, they miss preconnecting to `https://fonts.gstatic.com`, which is where the actual font files are served from. Adding `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>` improves font loading performance by initiating the DNS resolution, TCP handshake, and TLS negotiation early.
**Action:** Always include a preconnect to `fonts.gstatic.com` with the `crossorigin` attribute when using Google Fonts.
